com.phasmidsoftware.tableparser.core.parse

Parseable

Companion trait Parseable

object Parseable

The Parseable object provides a set of predefined Parseable type class instances that enable parsing of String representations into instances of various data types. These parsers operate based on the Parseable[T] trait, which defines a parse method that returns a Try[T].

This framework is designed to handle common data parsing scenarios with support for additional parsing behaviors through optional modifiers.

The parsers handle parsing errors gracefully, returning a Failure instance with an appropriate exception message when parsing fails.
