HierarchicalRenderer

com.phasmidsoftware.tableparser.core.render.HierarchicalRenderer

object HierarchicalRenderer

Object HierarchicalRenderer provides a collection of implicit instances and type definitions for the UntaggedHierarchicalRenderer trait, allowing for hierarchical serialization of various primitive and common types such as String, Boolean, Int, Long, BigInt, Double, and LocalDate.

These implicit objects define how to render instances of their respective types into a hierarchical structure (Node) by extending the generic UntaggedHierarchicalRenderer which implements the HierarchicalRenderer interface.

inline def derived[T](style: String, attrs: Map[String, String] = ...)(using m: ProductOf[T]): HierarchicalRenderer[T]

Method to derive a HierarchicalRenderer for a case class T, as a node with the given style whose children are its fields, each rendered by its own HierarchicalRenderer, with a "name" attribute giving the field's name. This replaces the renderer1 ... renderer13 methods of HierarchicalRenderers in 1.x.

Method to derive a HierarchicalRenderer for a case class T, as a node with the given style whose children are its fields, each rendered by its own HierarchicalRenderer, with a "name" attribute giving the field's name. This replaces the renderer1 ... renderer13 methods of HierarchicalRenderers in 1.x.

NOTE: because it takes a style, this is used as given HierarchicalRenderer[T] = HierarchicalRenderer.derived[T]("style"), not with derives. Each field's type must have a HierarchicalRenderer of its own.

NOTE: for a case class defined inside a method, see the NOTE on CellParser.derived.
