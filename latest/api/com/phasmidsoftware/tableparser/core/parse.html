The ParseableOption object provides implicit instances of ParseableOption for various types, enabling the parsing of optional Scala values.

ParseableOption works in conjunction with the abstract class of the same name, allowing strings to be parsed into optional values of specified types while handling blanks as None. This is achieved through the underlying Parseable evidence available for the corresponding type.

The implicit objects defined here provide type-specific implementations for common data types like String, Int, Boolean, LocalDate, and more.

case class RowConfig(delimiter: Char = ..., quote: Char = ..., listSep: Char = ..., listEnclosure: String = ..., trim: Boolean = ..., maybeString: Option[Regex] = ...)

Case class to define the configuration for parsing a row (see LineParser).

Case class to define the configuration for parsing a row (see LineParser).

The default reads CSV as defined by RFC 4180 (https://www.rfc-editor.org/rfc/rfc4180): fields are separated by commas, and spaces are part of a field; a field may be quoted (with "), in which case it may contain commas, line breaks and quotes (which are doubled).

The regular expressions which LineParser uses are derived from the characters, so that changing the delimiter (for example) changes everything that depends on it. Use the copy methods (withDelimiter, etc.) to change one property, e.g. given RowConfig = RowConfig.default.withDelimiter('\t') or simply given RowConfig = RowConfig(delimiter = '\t').
