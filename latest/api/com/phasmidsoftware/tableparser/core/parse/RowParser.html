trait RowParser[Row, Input]

Trait to describe a parser which will yield a Try[Row] from a String representing a row of a table.

def parseIndexedIf(header: Header, maybeRawPredicate: Option[RawRow => Boolean])(indexedRow: (Input, Int)): Try[Option[Row]]

Method to parse an indexed row, using the given header, unless it fails a raw predicate: the predicate is applied to the row's cells (as Strings) before they are converted, so a row which fails it costs only the splitting of its cells.

Method to parse an indexed row, using the given header, unless it fails a raw predicate: the predicate is applied to the row's cells (as Strings) before they are converted, so a row which fails it costs only the splitting of its cells.

This default can't apply a raw predicate (it doesn't know how to split the input into cells), so, given one, it fails rather than ignore it. StandardRowParser and StandardStringsParser can apply one.

Value parameters

header

the header which defines the schema or metadata for parsing the row.

indexedRow

a tuple containing the input row (of type Input) and its index (of type Int).

maybeRawPredicate

an optional predicate on the row's raw cells (None: parse every row).

Attributes

Returns

a Try of Some(row) if the row was parsed, or None if it failed the raw predicate.
