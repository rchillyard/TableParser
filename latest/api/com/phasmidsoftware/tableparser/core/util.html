The FunctionIterator class wraps an existing iterator to apply a function f to its elements, returning an iterator that yields Try[R], where R is the result type of the function application.

final case class TopN[T]

An immutable accumulator of the n best values seen so far: the greatest (TopN.greatest) or the least (TopN.least). It holds at most n values, however many it is given, so it can find, for example, the ten best rows of a stream which is far too big for memory.

An immutable accumulator of the n best values seen so far: the greatest (TopN.greatest) or the least (TopN.least). It holds at most n values, however many it is given, so it can find, for example, the ten best rows of a stream which is far too big for memory.

It keeps a priority queue (Visitor's PrioQueue, which is a binary heap) whose head is the worst value it holds. When it is full, a new value which is no better than the head is ignored; otherwise, it replaces the head. So each value costs O(log n) at most. Values which are equal (by the Ordering) are not kept in any particular order.

Type parameters

T

the type of the values.

Value parameters

n

the most values to keep.

ordering

the Ordering of the queue: a value which is lteq the queue's head is no better than it.

queue

the values kept, worst first.
