def stream(parser: StringTableParser[_])(source: => Source): Stream[IO, parser.Row]

Method to stream the rows of a table, as they are read: the whole table is never in memory. The source is opened when the stream is run, and closed when it ends (whether it completes, fails or is cancelled). The header is read first (as parser reads it); then each row is parsed as it is pulled. The parser's predicate selects the rows; if the parser is forgiving, a row which can't be parsed is logged and left out, otherwise the stream fails with its exception.

Method to stream the rows of a table, as they are read: the whole table is never in memory. The source is opened when the stream is run, and closed when it ends (whether it completes, fails or is cancelled). The header is read first (as parser reads it); then each row is parsed as it is pulled. The parser's predicate selects the rows; if the parser is forgiving, a row which can't be parsed is logged and left out, otherwise the stream fails with its exception.

The parser is passed as a value (not a given) so that the type of its rows is known: for example, IOTable.stream(MovieTableParser)(source) is a Stream[IO, Movie].

Value parameters

parser

a StringTableParser (e.g. a HeadedCSVTableParser, or a RawTableParser).

source

the Source (call-by-name: it is made when the stream is run).

Attributes

Returns

a Stream[IO, parser.Row].
