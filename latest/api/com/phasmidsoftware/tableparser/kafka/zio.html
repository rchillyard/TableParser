object ZIOKafka

ZPipelines which send rows to a Kafka topic, using zio-kafka: one message for each row.

ZPipelines which send rows to a Kafka topic, using zio-kafka: one message for each row.

By default, the value of each message is the row rendered as one line of CSV (with no line ending), and the column names, also as one line of CSV, are in the message's record header called columnsHeader. So each message describes itself: a consumer may start at any offset, and needs nothing else to read it. Alternatively, toKafkaWith takes a function to render each row (for example, as JSON), and adds no header.

The rows can come from any stream, such as one made by ZIOTable.streamFile, or from a Table (ZStream.fromIterable(table.content.toSeq)). The pipelines need a zio-kafka Producer (for example, from Producer.make(ProducerSettings(servers))), whose settings (such as batching, compression and acknowledgements) are zio-kafka's. For messages without a key, use unitSerializer, with the key function _ => (): Kafka then chooses the partition.
